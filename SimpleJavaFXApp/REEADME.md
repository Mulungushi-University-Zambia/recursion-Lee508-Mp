# SimpleJavaFXApp

A beginner JavaFX desktop application built for ICT261 Advanced Java Programming (Mulungushi University).

## What it does
Opens a window with a label and a button — clicking the button updates the label text.

## Tech stack
- Java 25
- JavaFX 25.0.1
- Gradle 9.7.1

## How to run
1. Clone the repo
2. Open in IntelliJ IDEA (JDK 25 required)
3. Run: `gradle run`
